# 📖 HR后台访问指南

## 访问方式

### 方式一：通过主应用导航（推荐）

1. 访问主应用：http://localhost:8501
2. 在主应用中应该有侧边栏导航或页面选择器
3. 选择"HR后台管理"或类似选项

### 方式二：直接启动HR后台应用

如果您想直接打开HR后台，可以停止当前应用，然后重新启动HR后台：

1. 停止当前应用（Ctrl+C）
2. 运行以下命令：

```bash
cd /workspace
streamlit run 03_项目代码/pages/hr/hr_dashboard.py
```

### 方式三：在主应用中添加导航

如果您希望从主应用直接导航到HR后台，需要在主应用中配置页面菜单。

---

## 常见问题

**Q: 为什么 http://localhost:8501/pages/hr/hr_dashboard.py 访问没有反应？**

A: Streamlit的页面访问方式与普通网页不同。正确的访问方式是：
- 要么通过主应用的页面选择器
- 要么重新启动应用指向特定页面

**Q: 如何确认HR后台页面是否可以正常加载？**

A: 直接启动HR后台页面来测试：
```bash
streamlit run 03_项目代码/pages/hr/hr_dashboard.py
```
