
# 智聘未来 AI 招聘系统 - 模块结构说明

## 📋 本项目已重构为模块化结构，以下是各模块的职责划分：

---

## 📁 核心模块

### 1. **config.py** - 配置管理模块
- 统一管理所有配置项
- 环境变量加载
- 路径配置
- MySQL配置
- API配置
- 邮件配置
- 面试配置

### 2. **utils.py** - 工具函数模块
- 简历文本读取（txt/docx/pdf格式
- 邮箱、性别、年龄提取
- 专业、学历、城市、城市提取
- JD内容读取
- 文本摘要（精简
- 通用工具函数

### 3. **database.py** - 数据库操作模块
- 数据库连接管理
- 简历记录保存
- 岗位查询
- JD查询
- 评分标准查询

### 4. **ai_scorer.py** - AI 评分模块
- LLM API调用
- 简历评分
- 结构化评分返回
- 智能追问
- 自由对话

### 5. **resume_parser.py** - 简历解析模块
- 简历上传解析
- 信息提取（姓名
- 正则+LLM双模式
- 临时文件管理

### 6. **email_service.py** - 邮件服务模块
- 发送邮件发送
- 面试邀请发送
- 面试结果发送
- 邮件状态管理
- 日志记录

### 7. **excel_service.py** - Excel操作模块
- 数据保存到Excel
- 面试分数更新
- 跨平台路径处理

### 8. **interview_service.py** - 面试服务模块
- Token生成/校验
- 面试题目生成
- 面试状态管理
- 面试评分
- 题目更新

### 9. **log_system.py** - 日志系统模块
- 对话日志
- 招聘日志
- 邮件日志

---

## 📁 兼容模块（保持原有接口）

### agent.py
- 对外保持原有process_new_files接口
- 内部调用新模块
- 兼容旧代码

### agent_service.py
- 保持所有原有接口保持不变
- 内部调用新模块
- 前端无需修改

---

## 📁 前端页面

- **app.py** - 旧版投递页面（保持不变
- **chat_main.py** - 对话式招聘页面（保持不变）
- **pages/interview_page.py** - 面试页面（保持不变）

---

## 📁 其他文件

- **gsh.py** - 原有工具脚本
- **import_jd_to_mysql.py** - JD导入脚本
- **text_data.py** - 数据生成脚本

---

## ✅ 重构优点

1. **单一职责**：每个模块只负责一项功能
2. **易于维护**：修改某个功能只需要修改对应模块
3. **易于测试**：可以独立测试每个模块
4. **代码复用**：通用功能封装在utils中
5. **配置统一**：所有配置在config.py统一管理
6. **接口不变**：对外接口保持不变，前端无需修改
