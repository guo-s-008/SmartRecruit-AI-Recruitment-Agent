## 🚀 在您自己的电脑上启动（超简单！）

### Windows用户：
1. **把整个项目文件夹复制到您的电脑**
2. **双击运行** `start_windows.bat`
3. 等待依赖安装完成，浏览器会自动打开！

### Mac用户：
1. **把整个项目文件夹复制到您的电脑**
2. **双击运行** `start_mac_linux.sh`（或者在终端运行 `bash start_mac_linux.sh`）
3. 等待依赖安装完成，浏览器会自动打开！

### Linux用户：
1. **把整个项目文件夹复制到您的电脑**
2. 在终端运行：`bash start_mac_linux.sh`
3. 等待依赖安装完成，浏览器会自动打开！
